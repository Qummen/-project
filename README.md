# Arbitrage Bot

Учебный проект на C++, моделирующий учебного арбитражного бота для криптобирж.  
Бот сравнивает цены на разных биржах(данные сгенерированы), ищет арбитражные возможности и может выводить уведомления через Telegram

## Идея проекта

Арбитраж - это ситуация, когда один и тот же актив можно купить дешевле на одной бирже и продать дороже на другой.  
В данном проекте бот:

 - получает цены с нескольких бирж;
 - сравнивает ask и bid;
 - находит потенциально выгодные сделки;
 - формирует пары ордеров: покупка и продажа.

Проект написан в учебных целях и демонстрирует базовую архитектуру торгового бота на C++

На текущий момент проект включает:

абстракцию биржи через базовый интерфейс Exchange;
 - реализации бирж:
